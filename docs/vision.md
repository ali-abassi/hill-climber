# Hill Climber

Make repeated improvement understandable and trustworthy across measurable
file-backed work. People and coding assistants should be able to define a goal,
choose a credible evaluator, run a bounded search and see which gain earned an
independent private promotion.

The product is a local workbench, adaptive instructions and a deterministic
controller. Code, performance, prompts, writing, file-backed design and
configuration are supported planning routes. Each still needs a useful score,
protected gates and fresh holdout cases. No interface or prompt can make a weak
metric meaningful.

Success means a faithful prepared command, readable verified evidence, honest
results and efficient small pilots. Real-model quality across domains requires
the frozen efficacy evaluations in docs/task-playbook.md.
