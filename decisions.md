# Decisions

2026-10-01: Ali clarified that optimization means improving the UI and the
instructions so the tool works effectively across kinds of work. Controller
throughput is supporting infrastructure; it is not evidence of better usability.
The repository contributor guide now records that distinction.

Use a small local workbench and six editable recipes. Keep real-run execution
explicit in the terminal, all prepared runs no-apply, and the trusted controller
unchanged except the candidate instruction contract. No new dependencies or
remote service are needed.

Separate development best, final kept score and private promotion. Reconstruct
display evidence from verified manifest/state/ledger, validate winner patch
bytes, and omit unchecked receipt metadata. Make demo execution POST and
same-origin, and terminate timed-out subprocess groups before releasing slots.

Keep candidate instructions compact, artifact-aware and evidence-driven. Test
delivery and boundaries now; do not claim universal model quality from fixtures.
Scale real searches only after evaluator validation and a small useful pilot.

Fixed external graders drive those versions with synthetic SDK streams; real Luna xhigh agents propose code. Protect valid candidate acceptance, session identity, source isolation, failure and usage accounting, exactly-one-document stdout, inspectable evidence, lock draining and recovery. ## 2026-10-02 — Expose the known Codex compatibility workaround separately

The installed SDK bundles Codex 0.149.0, which rejected the current local feature configuration during the PAL experiment. A session-local constructor adapter selected installed Codex 0.159.3 and completed real candidate turns. Expose that supported SDK option as HILL_CLIMBER_CODEX_PATH, using the same selected executable for login preflight and model launch. Preserve the original default when unset and the candidate environment allowlist. This is a direct known compatibility fix after the measured completion patch, not another holdout score claim. Do not edit global/account settings or silently switch binaries. A synthetic regression proves spaces in executable paths, auth consistency, constructor delivery and environment exclusions.
